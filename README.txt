Multiplayer aspects:
 - Slot machine jackpot is shared to all users
 - Blackjack is confirmed working with multiple users
 - In theory FIKA is not required, as long as the 'host' has port 6969 open anyone with this mod could join if pointed to the host IP in F12 config menu (not tested)

Dependencies:
 - ItemGen for Casino Coin item

Recommended:
 - Weekend Drops: (Casino Chips convert to GP coin in the casino, which can be turned into points in weekend drops. This is a pretty good economy cycle.)
 - To modify Casino Chip drops open the ItemGen webpage and add loot areas on a fake item, export json and you can copy the ID's from your fake item over to casino.json

F12:
 - Open / Close Slot Machine hotkey (Default F6)
 - SPT Server URL (default https://127.0.0.1:6969) --Set to main server IP if using Fika, this enables Jackpot sync, server settings sync, and multiplayer blackjack
